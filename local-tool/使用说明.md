# 阿祖 · 抖音创作台

双击桌面的「阿祖抖音创作台.app」（备用入口在项目文件夹的「备用启动.command」），或在服务运行时打开 http://127.0.0.1:8766/ 。

## 作品与数据页面

- 创作总览：仅汇总公开作品；互动包含点赞、评论、收藏、分享。
- 作品管理：公开/仅自己可见/全部筛选，标题搜索，排序，详情与 CSV 导出。
- 作品对比：按播放量、完播率、5 秒完播率、点赞、收藏、作品归因涨粉比较公开作品。
- AI 复盘：显示对应快照的数据证据、分析、行动建议与限制。
- 数据中心：导入抖音作品列表 `.xlsx` 或 TzFilm `.json`，查看与切换快照。

## 内容研究工作台（白色界面）

进入「爆款发现」，点击「添加赛道」打开分类选项，勾选后按「保存并自动查找」。不需要输入分类名称或搜索词；系统自动开始采集，以后沿用每日更新。默认「总览」汇总四个平台，平台页签和列表下拉框同步筛选。结果保留原链接与采集时间；未取得的指标写明“未取得”，YouTube 的收藏与分享等公开来源未提供的指标显示“未公开”。普通网页资料没有视频指标，不再显示一排空数字。搜索结果可以收藏，在详情里添加标签、备注和已经核对的字幕。

「素材收藏」支持筛选与 CSV / JSON 导出。「对标研究」把勾选的素材放入同一张对照表。「选题研究」按收藏标签整理主题，并显示完成的研究报告。一次最多选择 12 条素材。

点击「准备选题分析」或「准备创意分析」后，复制弹窗中的指令发到当前 Codex 对话。输入和 Skill 已打包；Codex 完成后会把报告写回工作台。当前使用 Codex 分析流程，网页没有连接独立模型 API。

右上角「导入数据」支持 MediaCrawler 或已有采集结果的 JSON / JSONL / CSV，一次最多 1000 条、5 MB。先导入作品，再导入关联的评论表；同一个来源链接会合并，重复评论样本不会反复增加。每条作品保留最多 100 条评论样本，样本不代表全部评论。

「工具连接」显示四项工具的实际状态。MediaCrawler 在线采集尚未启用：项目当前许可证限非商业学习研究，商业使用需作者书面许可。部分平台可能需要额外依赖或本人登录，遇到验证或限流时会停止本次收集。

### 图标、封面与指标补全

更新：1.2.0 起研究页只显示抖音、小红书、哔哩哔哩、YouTube，旧网页和其他平台记录保留在本机数据库，当前研究界面和导出不再包含。

内容赛道从弹窗分类选项中勾选添加，支持再次点击标签取消当前筛选、直接删除已选赛道，以及在「赛道与门槛」里暂停。弹窗取消不会保存，也不会发起采集；取消全部勾选并保存会停止后续赛道采集。页面只展示你已选的赛道，不会铺开全部分类。赛道是你的关键词研究方向，不是平台认证分类；已有素材与收藏在删除赛道后仍保留。

卡片直接展示五项互动指标。YouTube 单链接读取新增评论总数，仍不提供收藏和分享量；B 站搜索摘要可点击“更新数据”补充。小红书复用现有本机服务，点击“扫码连接小红书”，在手机确认后检查连接。小红书的“万”等缩略数字以 ≈ 标记近似量，公开来源缺少的播放数不会填成零。抖音目前通过采集文件导入，不提供实时关键词采集。

平台使用本地保存的品牌标识；普通网站优先显示真实 favicon，加载失败显示站点简称。封面优先使用来源图片，YouTube 使用对应作品的缩略图；取不到图片保留来源、标题与原因。没有填入装饰性假封面。

「补充预览」读取当前筛选列表前 12 条的公开网页头部预览信息。单条素材也可点击「补充封面与图标」。某些站点不提供预览或限制外链，仍可能显示来源标识。

视频详情中的「读取平台指标」支持 YouTube、哔哩哔哩，以及已登录的小红书；YouTube 可取得公开播放、点赞和评论，具体以来源返回为准。B 站读取使用公开接口，保留播放、点赞、评论、收藏、分享；搜索候选会在有限时间内补全互动数据。收集期间可以继续编辑备注，清空标签、备注和字幕后保存会生效。


### 个人赛道与爆款筛选

四个平台的默认最低点赞量均为 **50,000**。达到门槛且属于你已启用赛道的作品才进入默认爆款列表；缺失点赞数、真实零和低于门槛的作品都不会混入。数据以平台公开值或导入记录为准，约数会标注 ≈；点赞门槛只是选材筛选条件，不代表已验证内容质量或未来表现。

「更新爆款」按启用赛道查找候选并核对点赞量。采集和导入的低赞候选仍保留，可主动关闭「仅看5万赞及以上的作品」查看；刷新页面后恢复默认爆款筛选。不同平台的门槛可在设置里独立修改。

每日更新已并入现有 Codex 每日任务，频次仍为一天一次。可以关闭自动更新；没有启用赛道时不发起请求。定时入口为 `research_cli.py discover --scheduled`，会读取当时的最新设置并避免当天重复执行。每轮最多执行20个赛道平台查询，运行时间有边界；较多赛道按上次检查时间轮转，未处理数保留在任务记录。不是全网穷尽，也不保证每次都能找到达标作品。

抖音通过本人扫码连接，公开搜索与点赞读取验证通过后，才加入赛道自动采集；也可继续导入已有文件。小红书需要本人登录。平台验证、限流或不可用时停止相应平台，并在任务记录保留原因，不以低赞或虚构数据补齐。每日更新还依赖电脑联网和 Codex 可运行。


### 参考图主题与真实数据验证

当前主题参考用户提供的日本旅行拼贴海报，采用米白纸张底色、黑红字、藏蓝纸片边缘；页头拼贴使用本机已保存作品的真实封面，不制作虚构作品或互动数字。

B站热门候选改用现有 bili-cli 环境中的 bilibili-api-python 当前搜索接口，按播放排序取得候选，再读取点赞等公开指标。旧的无签名搜索接口已不再用于自动发现。YouTube 使用官网「热门程度」筛选地址获取候选，预设分类会匹配对应英文主题（例如人物故事对应 biography documentary，含外语原作），再读取实际点赞数，不能用播放量冒充点赞。

选择赛道的保存接口会直接发起采集，不需再点关键词搜索；若已有采集在运行，会保存选择并提示后续每日任务处理。已有导入、收藏、备注与分析流程保留。平台未登录或受限仍需本人完成相应步骤，这些不算作采集成功。


YouTube 单条作品的元数据异常会独立处理，其余成功结果保留。读取时只输出工作台所需的元数据，避免整包媒体格式列表过大导致整批失败。缺失点赞的作品仍不能进入爆款列表。平台读取不完整时任务显示「部分完成」；全部失败显示「本次未完成」，不会以「已完成」掩盖登录或来源错误。


### 抖音只读采集（dy-cli）

沿用本创作台，不新增网页。点击「总览」或「抖音」中的「扫码连接抖音」，在独立窗口使用本人的抖音 App 扫码并确认。登录成功后自动做一次公开搜索验证；仅有登录信息不算采集成功。验证通过后，已经启用的赛道会开始更新；没有选赛道时只验证，不替你添加分类。

采集桥仅开放公开视频搜索（最多点赞排序）、作品信息和本人扫码登录，读取真实点赞、评论、收藏、分享及封面。抖音公开搜索不提供可靠播放量，保留为空并显示「未公开」。不提取现有浏览器 Cookie，不调用发布、关注、点赞和评论发送命令；平台验证、限流停止当前平台，须本人检查。

独立环境及新扫码登录状态在 `~/Library/Application Support/TzFilmDouyin/` 内，登录文件权限为600，不进入项目仓库。来源版本、维护信息及固定提交见 `DY-READONLY.md`。接口可能随平台变化，连接成功不代表永久可用，也不保证任意分类都有5万赞候选。


抖音当前实测边界：公开搜索已重新实测，可返回点赞、评论、收藏和分享数；单条详情接口仍受限，保持暂停，不提供抖音单条刷新。详情端点的访问限制只暂停详情，不关闭独立验证通过的搜索；账号失效、平台验证或限流仍会暂停整个抖音采集。本人检查平台后可在连接弹窗点击「重新验证搜索」，使用现有扫码会话验证；检查状态本身不会重试请求或打开新登录窗口。未公开的播放量显示为空。


### 粘贴视频链接：收藏、对标和选题

「素材收藏」「对标研究」「选题研究」顶部均有「粘贴视频链接」。可以粘贴单条网址、多条网址或平台完整分享文案，每次最多12个链接。系统识别抖音、小红书、B站和YouTube，支持常见分享短链接，合并同一作品的常见跟踪参数。短链接只跟随受支持平台的公开跳转，不访问内网或任意外站。

- 素材收藏：点击「读取并收藏」，成功取得的标题、封面、简介及公开指标一起保存；未公开或未取得的指标保留为空。
- 对标研究：点击「读取并准备对标」，读取后自动收藏，并用已有资料准备创意对比任务。
- 选题研究：点击「读取并准备选题」，读取后自动收藏，并用已有资料准备选题任务。

输入框下方逐条显示「已读取」「仅保存链接」「保留原资料」或错误原因；点击「查看资料」打开素材详情。任务进行时自动更新，刷新后仍能查看最近同类链接任务。重复添加会合并，保留原有备注、标签和已核对字幕。

读取失败时可以保留真实网址，但只保存了网址不算取得了视频资料，也不会自动生成空洞分析。若此前已保存过资料，则保留此前数据和原采集时间。多条链接中一个平台需要登录、验证或限流时，停止本批次该平台的后续读取，其他可用平台继续。全批次处理有时间边界，到达后剩余链接仅保存，不无限等待。

手动添加的研究参考可以低于5万赞，不改变「爆款发现」的默认5万赞筛选规则。这里不下载视频、不保证取得字幕；标题和简介不当作字幕。分析仍交给当前Codex对话完成：点击「查看分析任务」，把显示的指令发到当前对话，完成后报告回到工作台。

抖音连接页分别展示「账号登录」「公开搜索」「单条详情」。已有登录文件只说明登录信息已保存，不保证会话永久有效；搜索曾通过不代表详情接口可用。当前详情接口受限时，粘贴抖音链接只保存网址，不重试接口、不重新弹扫码。小红书未登录时仅提示需要本人登录，不自动打开二维码。

链接读取成功但某项指标隐藏或未提供时，该项显示为空，不把旧数值当作这次新取得的值；整条读取失败时，才保留此前资料与原采集时间。


## 一键 AI 选题与对标分析

已按用户确认接入 OpenAI 官方开源 Codex CLI（本机现有安装），复用本人已登录的 ChatGPT/Codex 账号，不新建 API 密钥。

在「选题研究」或「对标研究」粘贴链接，读取到有效资料或能沿用已有有效资料时，自动开始对应分析；也可勾选已收藏素材，点击「开始 AI 选题分析」或「开始 AI 对标分析」。进度、错误和报告均自动回到当前网页，无需复制分析指令。每次最多 12 条素材，同时只运行一个 AI 分析；消耗 Codex 额度。未完成的旧手动任务不会偷偷批量执行。

分析只使用冻结的素材标题、简介、实际指标及用户已核对的字幕，结合 content-strategy 和 ad-creative 中适用的研究方法，不写口播。只有网址、未取得作品资料的条目不能单独分析。没有观看原片时不分析镜头和声音，不根据点赞推断完播率；近似计数保留标记。

后端通过只读、短时 Codex 执行返回结构化 JSON；禁用工作进程的 shell、其他 Agent、浏览器、插件、MCP 应用、Hook 和网页搜索，报告经格式、素材引用及输入哈希校验后入库。每次最长 5 分钟，额度、登录或响应异常会停止，不自动重试。登录仍由 Codex 自身管理，不复制登录凭据到网页或源码。系统重启中断的分析不自动重跑。

抖音原网页人工核对的资料标注来源为「抖音原网页核对」；“18.5万”之类缩略值显示为近似值。此项补全不意味着受限的详情 API 已恢复，也不代表所有新链接都能自动取得资料。


## 报告简读

选题研究和对标报告默认显示「一句话建议、最多3条重点、最多3条下一步、一次说明的信息缺口」。精简内容通常约220–320字，后端上限420字，保留近似数值和必要条件。点击「查看依据与完整分析」可展开原结论、证据和分析边界；完整内容不因收起而删除。

已存报告补充简读内容，原报告和冻结输入保留。以后由本机Codex生成的报告必须同时返回简读与较短的完整分析；超长、缺少简读或引用未知素材时，不保存成成功报告。

## 视频内容研究

侧栏统一为「内容研究」，分为「对标拆解 → 选题决策」。旧链接仍可打开，收藏、每日更新和既有报告保留。

1. 粘贴作品链接收藏，或选择已有参考。
2. 在「读懂参考视频」选择对应素材。YouTube / 哔哩哔哩可尝试平台字幕；勾选后，无字幕时尝试可获取原片。抖音、小红书当前使用本地导入。
3. 导入原片或音频：最多20分钟、500 MB。支持MP4、MOV、MKV、WebM、MP3、WAV、M4A、AAC。字幕支持UTF-8 SRT / VTT / TXT，最多1 MB、5万字。已有逐字稿会保留。自动转写标为待核对，展开修改后点击「保存并标为已核对」。
4. 点击「选为分析样本」，再「开始 AI 拆解」。报告给开头、结构、节奏依据、借鉴点和不可照搬之处；无时间证据不生成时间节点。
5. 报告下点击「用这份拆解形成选题」，沿用样本和拆解，给一个优先主题、切入角度、目标观众、理由与补证资料，不生成口播稿。
