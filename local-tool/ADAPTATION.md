本地版本位于 `local-tool/`：沿用上游 React、Recharts、Lucide 技术栈，改编 `dashboard/components/ui/card.tsx` 的 Card / CardHeader / CardContent 插槽结构和卡片组合方式。

## 内容研究整合（1.1.0）

基于原有 React + Python 本地服务扩展，保留同一个桌面入口与 8766 端口。新增 `research.py`、`research_cli.py`、`src/research.jsx`、`src/research.css`；页面新增搜索研究、素材收藏、对标研究、选题研究。

- MediaCrawler：仅适配用户已经取得的作品与评论导出文件（JSON / JSONL / CSV），没有复制或启动其在线采集器。作品按来源链接合并；评论按所属作品关联，不能覆盖作品标题、作者与指标。其非商业学习许可证不允许未经书面许可的商业使用，在线采集保持未启用。
- content-strategy 与 ad-creative：完整 Skill 放在用户的 GitHub 专属 Skills 仓库，Codex 技能目录通过符号链接指向该目录，保留 MIT 许可证与固定版本的来源记录。分别用于选题研究与有依据的创意复盘，排除写稿、广告文案与口播生成。
- 分析路径：网页冻结所选素材与输入 SHA-256，准备当前 Codex 对话可读取的任务包；Codex 生成带素材引用的 JSON 报告，再用 `research_cli.py finish` 回写。没有接独立模型 API，不把“准备任务”显示为“AI 分析完成”。报告保存原始输入快照，后续编辑素材不会改写旧报告依据。
- 存储：SQLite、输入包与报告放在现有用户应用数据目录的 `research/` 下，目录 0700，数据库与输入文件 0600；不提交 GitHub。原有每日采集时间、评论发送确认和账号状态未改动。

视觉使用已安装的 TasteSkill：`editorial-greeting`，seed `949074954`；保留用户指定的白色、浅灰、蓝色与系统字体，参考苹果官网的视觉层级。用真实浏览器截图与只读 DOM 检查桌面和手机断点；不通过另一套 CDP 浏览器修改用户会话。

验证：原有数据、评论与每日流程测试，加研究模块的导入、去重、零与缺失值、评论关联、任务冻结、来源引用、输入防篡改与导出检查。浏览器实测公开搜索、收藏、标签、对比表、分析任务及报告回写。真实搜索仅代表实测来源可用，不代表所有平台渠道均已登录或实测。
