# 数据分析平台

用于作品指标看板、数据对比、历史快照与导出分析的本地平台，保留现有跨平台内容研究能力。此仓库公开源码和使用说明，不含本人账号数据、评论、分析报告、登录态或密钥。

**这是源码仓库，不是在线数据分析服务。** GitHub 链接可公开查看和下载；完整工具需要 Python 后端、本机已授权的平台连接和 Codex 环境。GitHub Pages 只能托管静态页面，不能运行本项目采集与 AI 后台；当前没有部署公网后端或公开账号登录。

## 功能

- 作品数据导入、筛选、对比、CSV 导出及历史快照。
- 自选内容赛道与爆款门槛，抖音、小红书、B站和 YouTube 只读研究适配器。
- 分享链接识别、素材收藏、封面、公开指标和来源记录。
- 内容研究：对标拆解、选题决策及本机 Codex 分析报告。
- 本地视频字幕转写与镜头检测适配器。
- 评论整理、草稿编辑与具体批次确认；源码上传不会发送评论。

平台能力取决于本人授权、登录、接口可用性及访问限制；未取得的指标不视为 0。不提供绕过验证码或平台限制的功能。

## 本地启动

基础环境为 Python 3.12 和 Node.js。先安装前端和 Excel 读取依赖：

```sh
cd local-tool
python3 -m venv .venv
.venv/bin/pip install openpyxl
npm ci
npm run build
.venv/bin/python launcher.py --open
```

启动后在运行工具的同一台电脑访问 `http://127.0.0.1:8766/`。这不是公网网址，不能发给别人远程使用。

采集、评论、AI、视频转写的附加环境与授权需分别准备；当前源码保留原本机运行路径，跨电脑恢复和 Linux 部署尚未验证。不要把自己的 Cookie、密钥或作品导出提交到公开仓库。
